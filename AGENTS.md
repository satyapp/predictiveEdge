# PredictiveEdge project instructions

## Docker operations

- Do not execute Docker or Docker Compose commands for this repository.
- This includes build, pull, deploy, create, up, down, start, stop, restart, recreate, logs, exec, inspect, prune, and other Docker lifecycle or diagnostic commands.
- When Docker work is required, give the user the exact commands to run locally, explain briefly what each command does, and wait for the user to provide the result before continuing verification.
- Prefer non-Docker source compilation and static checks when they are sufficient.
- Do not start temporary container builds or services for verification because they consume significant time, temporary storage, memory, and OS resources on the user's machine.
- Clearly separate commands that are required from optional diagnostic commands.
